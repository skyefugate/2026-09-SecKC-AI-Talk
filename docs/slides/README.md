# Slides

The deck goes here as `slides.pdf`, and the card on the
[landing page](../index.html) links to it once it exists.

The source deck is a 144&nbsp;MB PowerPoint file, which is over GitHub's 100&nbsp;MB
hard limit for a single file, so it needs exporting and compressing first. Target
something under 25&nbsp;MB — the SecDSM deck landed at 2.7&nbsp;MB.

When the PDF is in place, turn the heading on the landing page back into a link:

```html
<h3><a href="slides/slides.pdf">The deck</a></h3>
```

and drop the `.pending` paragraph in that card.
