Network Mapping & Discovery

Network folks get pulled into unfamiliar environments constantly. We need a way to see the thing quickly.

Demo prompt

Demo 3 · Extra credit

Architecture Documentation

When did you last update the diagram after shipping a band-aid fix? Right. Mhmm. For environments managed as code, we can generate them.

Demo prompt

Hi GLaDOS, write a script that runs on GitHub Actions that as I push an IaC change it will update my architecture documentation. Express this as a living README doc using Mermaid in the folder of our IaC template in this repo.

Watch for A quick and easy to understand architectural diagram.

This one runs live against this repository. The CloudFormation template is already committed at iac/vpc-baseline/ — the workflow and the diagram are what get written on stage.
